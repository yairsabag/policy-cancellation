# UCP v2026-08-25 compatibility

This document records the exact compatibility claim for policy.cancellation v0.3.0.

## Status

- UCP v2026-08-25 standardizes the generic `policies[]` envelope on Catalog, Cart, Checkout and Order.
- `io.github.yairsabag.policy.cancellation` is an independent third-party policy type in the open reverse-DNS vocabulary.
- It is not a UCP-authored `dev.ucp.*` policy type.
- Platforms that do not recognize the type can still present its required human-readable `description`.

## Surface targeting

| Surface | Target used in fixtures |
| --- | --- |
| Catalog search | `$.products[0]` |
| Cart | `$.line_items[0]` |
| Checkout | `$.line_items[0]` |
| Order | `$.line_items[0]` |

The files under `examples/surfaces/` are policy-placement fixtures, not complete UCP response documents. The validation script validates every cancellation policy entry against the local schema.

## Forward compatibility

The v0.3 schema follows UCP schema-authoring guidance for vocabularies that may grow:

- `kind`, `relative_to`, payout methods and rule keys are open;
- readers must tolerate unknown values;
- known outcome kinds still receive conditional validation;
- unknown kinds retain their fields instead of failing deserialization.

## Executable evidence

Run:

```sh
npm install
npm run validate
npm test
```

The reference evaluator is descriptive only. It does not execute cancellations, authorize refunds, resolve legal overrides or replace the merchant's authoritative decision.
